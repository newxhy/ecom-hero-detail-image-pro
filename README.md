# 跨类目电商主图 + 详情页 AI 作图技能 · 使用说明

> 技能名：`ecom-hero-detail-image-pro`（v2.0.0）
> 一句话：给它一个产品的真实图 + 几句卖点，它帮你规划整套电商视觉，先出「版式稿 + 逐屏提示词」给你确认，再用图像模型批量出主图和详情页成品。适用任何品类、主流电商平台。

> ## ⚠️ 运行环境：**千问办公（QwenWork）专用**
>
> 这套流程的**阶段B（批量出图）强依赖千问办公内置的 `qwenwork_image_generate` 工具**（模型 open-image-2 / banana-image-2），出图纪律也是按它在实测中的具体行为写的：
>
> - edit 模式的参考图必须先复制进**会话工作目录**，外部路径直接报错；
> - 一次最多 4 个任务并发，第 5 个被拒；
> - 生成图右下角自带"AI生成"水印，只能靠竖幅留白带裁切去掉，提示词去不掉；
> - open-image-2 对婴儿形象硬拦截（生成和编辑都拒）。
>
> **换到 WorkBuddy 等其他 Agent 平台，没有这个工具，阶段B 跑不通。**只有阶段A（规划 + HTML 版式稿 + 逐屏生图提示词）是纯文本产出，任何平台都能用；真要移植，请先确认对方的生图能力，再改写"出图纪律"那一节。

## 一、它能帮你做什么

- **主图**：5 张（800×800），首屏定位 + 各卖点，干净防牛皮癣。
- **详情页**：按"买家决策顺序"排的一整套长图（头图→痛点→卖点→展示→细节→参数→场景→对比→资质→品牌→服务→保障）。
- **两种交付**：
  - 阶段A：文案结构 + HTML 版式稿（**每屏生图提示词已内嵌，可一键复制**）。
  - 阶段B：用图像模型把每屏出成成品图。
- 换任何品类都走同一套流程，不用重新摸索。

---

## 二、开始前的准备（越全，方向越准）

1. **产品真实图**（最重要）：白底实拍图 / 官方图。**AI 不会重绘你的产品**，产品长什么样以你的图为准。没有的话，可让它从品牌方天猫详情页抓真图。
2. **竞品图**（可选但推荐）：2–3 家同品类做得好的主图/详情页，用来定风格。
3. **基本卖点**：产品叫什么、卖给谁、最想让人记住的 3–5 个点、使用场景。
4. **目标平台**：淘宝/天猫 / 京东 / 拼多多 / 亚马逊（尺寸和红线不同）。

> 提示：说明书、参数表、备案号、真实评价这些"精确信息"如果有，一并给它，能直接填进对应屏，不用留白。

## 三、怎么用（三步）

**第 1 步：触发**
直接说，例如：
- "帮我给这个产品做一套淘宝主图 + 详情页"（附上产品图）
- "按电商作图技能，走一遍这个品"

**第 2 步：回答它的提问**
它会先问你：交付模式（只要提示词 / 直接出图）、平台、卖点定位。你照答即可。它会先当"买家"列出 8 条购买顾虑，再据此规划每一屏。

**第 3 步：先审版式稿，再出图**
- 它会先给你 **HTML 版式稿**（每屏文案 + 版式 + 内嵌提示词）。**这一步请你确认**：卖点取舍、顺序、风格对不对。
- 确认后回复"出图"，它用图像模型逐屏生成成品，最后拼一张详情长图 + 打包交付。

| 淘宝/天猫 | 800×800 | 750 或 790 | 文字≤20%、防牛皮癣（别贴促销/价格/水印） |

## 六、必须知道的几条规则（也是它的"底线"）

1. **产品保真是底线**：颜色、外形、logo、结构一律以你的真图为准，AI 不重绘。多色/配色屏用真实产品图，不让模型改颜色。
2. **图像操作交给图像模型**：抠图、合成、换背景、边缘融合、去水印都用模型，不做生硬手贴。
3. **真人/儿童照片**：图像模型出于安全会拒绝编辑真实人物（尤其小孩）照片；这类生活照会**原样嵌入相框 + 排版**，不送模型重绘。需要 AI 生成的婴儿场景，用允许的平台（如豆包）出图再本地处理。
4. **精确信息留白或如实填**：备案号、参数表、密集小字模型会写错——有真实数据就如实填，没有就留白后期贴，绝不瞎编。
5. **不碰的红线**：不画按钮/仿 UI、不上价格促销、不自造徽章/盾牌、不出现竞品品牌名、不用 AI 画备案号。

## 七、常见问题

**Q：能在 WorkBuddy 或其他 AI 工作台上用吗？**
A：**不能整套跑通，本技能是千问办公专用。**阶段A（规划 + HTML 版式稿 + 逐屏提示词）是纯文本，任何平台都能出；但阶段B 依赖千问办公内置的 `qwenwork_image_generate` 图像工具，别的平台没有这个工具，"批量出成品图"这半步直接断掉。要移植，得先把出图那一节的工具名和模型行为换成对方平台的等价能力。

**Q：为什么先给我版式稿，不直接出图？**
A：一套图几十张，直接全量出图又慢又费额度、还容易方向跑偏。先确认版式和文案（阶段A），再批量出图（阶段B），返工最少。

**Q：出的图能直接上架吗？**
A：主图/成品图已按平台规格出、无水印。但"留白位"（备案号、参数、真实评价等）需要你补真实数据后再上架——这些是合规信息，不能由 AI 编。

**Q：换个品类能用吗？**
A：能。流程、规格、红线、页面动线都通用，你只需换产品图和卖点。

**Q：怎么分享给同事？**
A：把 `.skill` 文件发给对方，在千问办公里点"保存技能"即可安装使用。
